# Android localization inputs

This is an incomplete phone localization effort. `es.json` covers all 1183 currently externalized app/platform strings/plurals, including the five onboarding pages, bottom navigation, recording controls, support, import review, optional analytics, the current-recording map layer, visit editing, timeline day/row controls, outing details, route replay and primary photo workflows and geographic photo browsing, routing consent/credits and Visits only. Many screens and service/permission messages still contain English literals. Other iOS languages, complete Spanish workflows, terminology/editorial review, TalkBack and release acceptance remain open. No complete language-support claim or per-app language picker is added.

Edit the default resources in `app/src/main/res/values/` or `platform/src/main/res/values/` and the corresponding translation input together. The explicit `defaultSourceSha256` freezes the reviewed English input: changing wording requires reviewing translations and deliberately updating this hash. The generated coverage report contains the current source hash to compare against, but the generator never updates an input hash automatically. Recompute it after review with Python using `defaults()` and `json.dumps(..., ensure_ascii=False, sort_keys=True)` from the generator.

Run from the repository root:

```sh
python3 android/scripts/generate_localized_resources.py
python3 android/scripts/generate_localized_resources.py --check
python3 android/scripts/test_localized_resources.py
```

The generator validates one reviewed pack, then writes `values-es/generated.xml` separately into the owning app/platform resource module and updates `coverage.json`. Duplicate keys across modules and unowned generated keys fail. Coverage records aggregate and per-module counts/hashes. Do not edit generated outputs. CI checks them and validates the conversion rules. New default keys require translations; unknown/duplicate mappings, missing plural categories, changed argument identities/types, unsupported formats and stale outputs fail. Only reviewed static catalog entries with matching English text can be aliased from `IsoMe/Localizable.xcstrings`; this first pack reuses Map, Timeline, Export, Settings and Continue. Swift placeholders and plural structures require explicit conversion before reuse. Android-specific copy, errors and plurals are mapped directly in the pack. Spanish wording is an implementation draft pending final language and privacy/store review.
