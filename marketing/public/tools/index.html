iPhone location journals

Make sense of your location files

Practical tools for checking your own files before importing or converting them.

By Cody Bontecou, Whereday’s developer · Reviewed October 30, 2026

GPX viewer and file inspector

Plot tracks and routes, check timestamps and invalid coordinates, and save CSV or GeoJSON with documented field limits. Your chosen file stays in your browser.

Follow the worked inspection tutorial with an invented five-point example.

Have a different file type? Compare GPX, KML, GeoJSON and CSV before choosing a destination. The current viewer accepts GPX; renaming a file does not convert it.

Google Timeline JSON inspector

Identify supported raw, semantic and device Timeline structures. Check coordinates and times, inspect findings and try invented examples before opening your own archive.

Learn which Timeline JSON file you have and why browser counts can differ from a native import preview. Your selected file stays in the tool page.
