Drop a KMZ, KML or GPX file. It stays on this device.

A KMZ becomes a GPX 1.1 file. A GPX becomes a KMZ, with a plain KML as a second download. The direction comes from the file’s content, not its name: a zip signature means KMZ, and a <gpx> root means GPX. A plain .kml is converted to GPX too. Before you download, a report lists which file inside the KMZ was read, what was converted and what was left out. No account, upload or analytics. The file is read with your browser’s File API, and a KMZ is unzipped with the browser’s built-in DecompressionStream.

        What a KMZ is

        A KMZ is a zip archive. Google’s KMZ archives guide describes it as a KML file packaged together with the files it refers to, such as icons and overlay images, so they travel as one file. The KML at the top level is normally called doc.kml. This tool reads doc.kml and, if there is none, the first .kml at the top level of the archive. If you got a .kmz from Google Earth, a map you exported or a download link, the coordinates are in that KML, and a GPS app or watch that only reads GPX cannot open the archive.

        You can rename a KMZ to .zip and look inside, but you do not need to: drop the KMZ as it is. To see what is in it before converting, use the KML and KMZ viewer.

        What survives each conversion

        KML writes a coordinate as longitude,latitude[,altitude]; GPX uses separate lat and lon attributes. The tool swaps them for you and copies the digits as written. The same converter is used by KML to GPX, which explains each element in more depth.

        The KMZ this tool writes has one entry, doc.kml, stored without compression. The KML download is the same content without the zip. The output is the same every time for the same input.

        Using the result

        • GPS apps and watches that ask for GPX: use the GPX from a KMZ. Open it in the GPX viewer first and compare its counts with the report. To join several, use Merge GPX.
        • Google Earth or Google My Maps from a GPX: use the KMZ or KML. For Earth, check Google Earth Help for the current import steps. For My Maps, Google lists the supported file types in its import help. The site’s guide to opening a GPX file in Google Maps shows the My Maps steps on a computer.

        We have not tested every app or device with this tool’s output, so open a small file first. The GPX is checked against the GPX 1.1 schema in the site’s tests, and the KMZ is reopened in the KML viewer’s reader with the same placemark and line counts. Want a spreadsheet instead?         Limits

        • One file, up to 10 MiB and 50,000 coordinates, the same limits as the sibling tools. A file inside the KMZ is also limited to 10 MiB uncompressed.
        • ZIP64 KMZ files are refused with a message. Re-save the file as a standard KMZ, or unzip it and choose the doc.kml inside. Encrypted archives and compression methods other than stored and deflate are refused too.
        • Browsers without DecompressionStream cannot unzip a KMZ; the page says so. Use a current Safari, Chrome, Edge or Firefox, or unzip the file yourself. GPX and plain KML do not need it. See MDN’s DecompressionStream page.
        • Several KML files. Only one is converted: doc.kml, or else the first top-level .kml. The others are counted as ignored.
        • Linked files. A KMZ includes files it carries. A KML that points to files elsewhere (a NetworkLink, an image URL) is not followed, because the page makes no network requests.
        • Polygons are skipped; GPX has no area shape.
        • Altitudes are copied as written. KML altitude modes are not interpreted.
        • Files with a DOCTYPE or entity declaration are refused.

        File privacy

        Your file is read, unzipped, converted and saved in this page. The page’s content security policy blocks network connections and it loads no analytics, so it cannot send the file anywhere. The web server sees an ordinary request for the page and its scripts, not your file or its name. Keep your original file: the tool never changes it.

        Questions

        Is my file uploaded?

        No. See file privacy.

        Why are my photos missing?

        GPX holds points, routes and tracks, not pictures. Images inside the KMZ (icons, overlays, photos) are not converted and the report counts them under “Images ignored”. Your original KMZ still has them.

        Can I convert KMZ to CSV?

        Yes, with the KML or KMZ to CSV converter, which writes one row per placemark or per vertex.

        My KMZ has several layers. Which one is converted?

        A KMZ has one KML that is read: doc.kml, or the first .kml at the top level. Folders inside that KML are all converted, but GPX has no folders, so their names are lost and the report counts them. If the layers are separate KML files, only the chosen one is converted and the rest are listed as ignored; unzip the KMZ and convert the others one at a time with KML to GPX.

        Why is my polygon missing?

        GPX has no area shape, and the tool does not turn an outline into a track. Polygons are skipped and counted in the report.

        Does Whereday import KMZ or GPX?

        No. Whereday exports GPX, KML and other formats; it does not import GPX or KMZ.
