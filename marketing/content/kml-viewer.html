          What is a KML file, and what is a KMZ?

          KML (Keyhole Markup Language) is an XML format for places and shapes: placemarks, lines, polygons and folders that organise them. It is an OGC standard, and Google’s KML reference documents Google Earth’s extensions, such as gx:Track, which pairs each position with a time. Coordinates are written longitude,latitude[,altitude] in WGS84, so longitude comes first.

          A KMZ is a KML file inside a ZIP archive, usually together with images or other files it refers to. Per Google’s KMZ guide, the main file is doc.kml; if there is none, the first .kml at the top level is used. This viewer follows the same rule. For the differences between KML, GPX, GeoJSON and CSV, see which format to choose.

          How to open a KML or KMZ file

          • This page. Choose the file above. Nothing is uploaded, and it shows what is inside, including what it skips. It draws shapes only, not a map.
          • Google Earth. Google Earth on the web, on the desktop and in its mobile apps can import KML and KMZ files and draws them with their styles. See Google Earth Help for the current import steps.
          • Google My Maps. It can import some files into a map; its supported file types are listed in Google’s import help. For a GPX file, see how to open a GPX file in Google Maps.

          We have not compared the results with Google Earth, and this viewer does not claim to match it.

          Opening a KMZ on iPhone

          We have not tested this page in Safari on an iPhone, so we give no iPhone steps here. The page uses only your browser’s file picker and its built-in unzip support (DecompressionStream); if your browser lacks it, the page says so. A computer is the tested route: open the KMZ in desktop Safari or Chrome.

          Synthetic examples

          These files are invented, near 0° N 10° E, and are not anyone’s recording. synthetic-kml-viewer.kml has 1 folder, 2 Points, 1 LineString, 1 Polygon with 1 inner ring and 1 gx:Track of 5 timed positions. synthetic-kml-viewer.kmz (deflate) and synthetic-kml-viewer-stored.kmz (stored) hold the same doc.kml plus a one-pixel image, which is listed but not drawn. The buttons above load them.

          Limits

          • One file, up to 10 MiB (and 10 MiB once unzipped) and 50,000 coordinates, in line with the other tools here.
          • KMZ: stored and deflate entries only. Encrypted, ZIP64, split and other-compression archives give an error. Only one KML is opened, doc.kml or else the first top-level .kml.
          • No styles or icons are rendered, and no overlays, 3D models or tours.
          • No network links are followed; this page makes no network requests.
          • No reprojection. KML is WGS84 longitude, latitude, and values outside ±180 and ±90 are skipped. The plot is a simple local projection with no map, and does not handle shapes that cross the 180° meridian.
          • Altitude is shown as written; altitude modes are not interpreted.
          • Files with a DOCTYPE or entity declaration are refused.

          Privacy: your file stays in the browser

          Unzipping, parsing and plotting all happen in this page. Its content security policy blocks network connections, the page loads no analytics and no map tiles, and descriptions are inserted as text, not HTML. The web server sees an ordinary request for the page and its scripts, not your file. Following a link leaves this page. Clear removes the result from the page and never changes your original file.
